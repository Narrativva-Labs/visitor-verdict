# Privacy and data minimisation

The detector reads these inputs locally (optional probes only when enabled):

- Navigator: `userAgent`, `userAgentData.brands` and each `brand`, `webdriver`, `languages` (length and entries), `language`, `userLanguage`, `browserLanguage`, `systemLanguage`, `plugins.length`, `pdfViewerEnabled`, `maxTouchPoints` and `hardwareConcurrency`. No high-entropy UA-data request is made. The local worker reads `userAgent`, `webdriver`, `languages` and `hardwareConcurrency` too.
- The optional worker additionally checks `userAgentData` property presence and `userAgentData.brands` array shape/length; it returns only a boolean, never brands. Geometry additionally reads `screen.availWidth`, `screen.availHeight`, `document.fullscreenElement` and `matchMedia('(display-mode: fullscreen)' / '(display-mode: standalone)').matches`. No high-entropy UA-data request is made.
- Window/document: `top`, `screen.width/height`, `innerWidth/innerHeight`, `outerWidth/outerHeight`, `document.visibilityState`, `document.prerendering`, `document.hasFocus()`, `isSecureContext`, `chrome`, configuration and existing detector state. It enumerates own window/document property names and reads matching property descriptors and their `value` fields, including the public `__visitorVerdict` property during inclusion checks. Shape checks inspect candidate `window`, `nodeType`, `ownerDocument`, object type and prototypes to reject host/DOM/window objects.
- Automation candidates: window `callPhantom`, `_phantom`, `__nightmare`, `domAutomation`, `domAutomationController`, exact `__playwright__binding__`, `__playwright__binding__controller__`, `__pwInitScripts`, and names matching `cdc_[A-Za-z0-9]+_(Array|Promise|Symbol|Object|Proxy|JSON|Window)`. Document candidates match `__(selenium|webdriver|driver|fxdriver)_(evaluate|unwrapped)`, `__webdriver_script_(fn|func|function)`, `__$webdriverAsyncExecutor`, and `$cdc_` / `$wdc_` prefixes. Names/values are not exported.
- Opt-in WebGL: canvas `getContext('webgl'/'experimental-webgl')`, extension availability through `getExtension`, `WEBGL_debug_renderer_info.UNMASKED_RENDERER_WEBGL` and its renderer via `getParameter`, and `WEBGL_lose_context.loseContext` for cleanup. It draws no fingerprint image or canvas pixels.
- Agent UI markers: `document.getElementById` for exactly three fixed IDs (`claude-agent-glow-border`, `claude-phantom-cursor`, `codex-agent-overlay-root`) and a reference comparison of each found element's `parentNode` with `document.body` / `document.documentElement`. Only presence at the expected parent is used. No element content, text, attributes, other IDs, URLs or page structure are read, collected or exported; the result is reduced to the operator enum `openai` / `anthropic`. Until a marker is found, a `MutationObserver` on `document.documentElement` triggers the same three lookups per batch and never reads its mutation records; it disconnects on the first match or on `pagehide`.
- Permissions: `Notification.permission`, availability of `navigator.permissions.query`, and the returned notification permission `state`. It never requests notification permission.
- Timing/history: `Date.now()`, `performance.getEntriesByType('navigation')[0].type` or legacy `performance.navigation.type`, and the stored `timestamps`, `lastClass` (including `value` / `direct`) and `tpPages` below.
- Input: event `type`, `isTrusted`, `pointerType`, `detail`, `clientX`, `clientY`, **`movementX` and `movementY`**. It retains short-lived observation times, a bounded path counter and jump flag, not event objects or a trajectory. Behaviour scoring does not inspect event targets, typed keys, text, page content, URLs or browsing destinations.
- WebMCP: one start-time presence check of `document.modelContext` and legacy `navigator.modelContext`; `toolactivated`/`toolcancel` event type and strict `isTrusted`, plus `currentTarget`/`target` identity only to avoid counting a context event again at window. Only the enum `none` / `capable` / `used` and a per-document count capped at 255 are retained. No target content, tool names, arguments, results or invocation identifiers are read. Observation continues after final until pagehide; these values never enter storage or affect class/score.
- Integration/capability checks: configured data-layer availability, `length` and `push`; DOM listener and timer APIs (including passive-option support), `Worker`, `Blob`, `URL` / `webkitURL` and their object-URL methods, worker messaging/termination, worker message `data.m` / `data.h` booleans and error `preventDefault`. These support local execution and cleanup, not additional scoring attributes.

Raw values are reduced to flags locally and discarded after use. Main navigator values pass only to the local worker, whose reply contains booleans; the worker is terminated and its Blob URL revoked. Pointer state is bounded to the latest move/click, timing, jump and small path-count fields and cleared at final; no click trace is collected.

The only detector storage is **one `sessionStorage` entry named `visitor_verdict`**, containing exactly these three keys:

```js
{
  timestamps: [/* newest fastNavCount pageview times; default maximum 3 */],
  lastClass: '', // class string, {value: 'suspicious' | 'automated', direct: true}, or {value: 'declared_agent', direct: true[, agent: 'openai' | 'anthropic']}
  tpPages: 0    // integer 0–255
}
```

- `timestamps`: finite nonnegative nonfuture times, rounded **down to 100ms**, deduplicated, sorted and limited to `fastNavCount` (default 3, configurable up to 20). Reload/back-forward does not append. Writes merge current storage so stale finalizers preserve newer page times.
- `lastClass`: initially an empty string; normally a final class string. A result with direct evidence stores provenance instead: `{value: 'automated', direct: true}` only for direct hard evidence in that document, and `{value: 'declared_agent', direct: true}` for a direct declaration (UA token or agent UI marker), also when carried CA made the document automated, so a declaration never renews automation. It is written at final, at the agent phase, at initial when a marker is present at load, and when a marker confirms a carried operator. When an agent UI marker was seen in that document the declared record also stores `agent: 'openai' | 'anthropic'`, which the next document carries with CD and then drops. Any other `agent` value, and any `agent` on an automated record, is ignored. **CA consumes that direct provenance at the next document's initial processing**, converting it to a plain string even if that document never finalizes. That document is automated via CA, which takes precedence over a declared identity. CA alone cannot renew provenance; a second consecutive document without direct evidence has no CA. A legacy/plain `automated` string does not seed CA. Fresh direct evidence on a carried document can renew it. Stale finalizers preserve a newer stored class/provenance.
- `tpPages`: bounded, saturating count of observed TP documents, incremented once per document before navigation. Missing, invalid, noninteger and out-of-range values reset to 0. At final, accepted activity without TP decrements it by one, down to 0; no activity or current TP leaves history undecayed. Decay occurs before checking TR. It is guarded against newer documents, changed class snapshots or changed counters, so stale finalizers cannot repay newer evidence or resurrect a decayed count. It is not a lifetime total, unique-URL count or time-based expiry.

No signals, raw properties, coordinates, URLs or IDs are stored. Storage denial does not stop local classification/output, but removes cross-document history. Records longer than 2,048 characters are ignored before parsing and writable storage is repaired to the minimal schema. Only the v1 key is read; previous keys are ignored, with no migration. The current-class GTM variable reads validated public globals, not storage. `window.__visitorVerdictLast` captures the previous validated stored class once at detector startup, including a consumed carry or a marker publication before final.

There are **no cookies, localStorage, hashes, fingerprints or identifiers** in the detector. **The detector makes no requests itself; if CSP blocks the Blob worker, the browser may send a CSP violation report to the site's endpoint.** Production data-layer output contains only the fixed event name, class, phase, numeric score, static `traffic_version`, informational `traffic_webmcp` and bounded `traffic_webmcp_count`, and, when an agent UI marker named it, the operator enum `traffic_agent` (`openai` | `anthropic`). Downstream tools such as GA4 attach the result to their own identifiers; in advanced consent-mode setups, an event may reach Google as a cookieless ping before consent. Installing this library does not change those tools' collection, storage or consent settings. The local test site separately posts debug events to `/log` and maintains test-only event history; that instrumentation is absent from the detector and GTM HTML.

The detector writes to `sessionStorage` and reads device/browser properties. [EDPB Guidelines 2/2023](https://www.edpb.europa.eu/system/files/documents/2024-10/edpb_guidelines_202302_technical_scope_art_53_eprivacydirective_v2_en_0.pdf) treat storing/reading such information as within the technical scope of Article 5(3) of the ePrivacy Directive regardless of cookies, including local processing. This project does not assess exemptions; site owners decide the applicable setup with their DPO.

For withdrawal, `sessionStorage.removeItem('visitor_verdict')` clears the stored local record. It does not erase already-published state, data-layer events or downstream data, and an active detector can write again at TP/final. Integrate withdrawal with gating future loads/analytics and clearing storage after active observation has ended; the detector has no consent listener or stop API.

## Consent and deployment

The supplied GTM detector runs on All Pages, once per page, with no additional consent check. Establish consent defaults through the site's consent integration before All Pages; do not use Initialization for the detector. The script does not read consent or grant it. The site owner decides the applicable setup with their DPO; this library does not establish a legal exemption.

Retain the Google tag's built-in consent behaviour and the site's CMP defaults/updates. Keep pre-consent classification out of advertising tags, remarketing and ad-platform exports. If the owner chooses to load only after analytics consent, gate detector loading and analytics accordingly, including a consent-granted trigger after the update for late grants: blocked All Pages tags do not automatically replay. Observation starts at actual load. The readiness timer can start the Google tag without a class; it does not override consent. See [GTM consent and readiness](ga4-reporting.md#consent-and-timing).

Production public snapshots expose only class, score, phase, version, WebMCP enum `webmcp`, bounded `webmcpCount` and the optional operator enum `agent`. Debug signal codes are opt-in data-layer fields only and are absent from the snapshot. All page scripts can read the data layer and public globals; [snapshot hardening](how-it-works.md#hardening-and-its-limits) does not turn them into a security boundary.

Suspicious carry stores `{value: "suspicious", direct: true}` only for current-document evidence.
The next document consumes it to the passive string `"suspicious"` before applying CS; a failed
write means no carry. CS-only finalization preserves the string without renewing provenance.
Plain suspicious strings are passive, including records from the earlier 1.2.0 implementation.
No storage field or identifier is added. The same successful-consumption requirement applies to CA/CD.

Version 1.4.0 adds only element-shape checks (tag name, attribute count, light-DOM child-node count, computed display) for the experimental Claude host. It never reads shadow content or attribute values. Form signals read event trust, type, inputType, composition, target tag and timing, never form values/text. One target reference and at most three times are discarded at final. Optional data-layer `traffic_agent_claim` / snapshot `claim` is the fixed enum `dom_host` with declared_agent only, not stored or mapped by the supplied GA4 tag.
